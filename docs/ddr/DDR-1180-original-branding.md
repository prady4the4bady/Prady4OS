## 2. Decision: rules for every brand asset

1. **Source of truth.** Assets are hand-written SVG in `assets/brand/`. They are text, reviewable in a diff and generated by no tool. Exports such as PNG and alpha atlases are build outputs under `build/`, never committed.
2. **Grid.**
   - Icons use a 24×24 unit `viewBox="0 0 24 24"`, with a 2-unit safe margin, so the live area is 2..22.
   - Stroke is 2 units, with round caps and joins.
   - Corner radius is 2 units on rectangles. The minimum gap between strokes is 2 units, so 16 px renders stay legible.
   - The logo and wordmark use their own `viewBox`, recorded in `assets/brand/README.md`. They follow the same stroke rule at their reference size.
3. **SVG subset.** The gate checks for exactly this subset, which keeps the build's rasteriser small and auditable:
   - elements: `<svg>`, `<path>`, `<circle>`, `<rect>`, `<line>`, `<g>`;
   - path commands: `M L H V C Q Z`, absolute or relative;
   - no `<text>`, no `<image>`, no `<use>`, no `transform` attribute, no filters, no gradients;
   - colour is only `currentColor`, so icons take the theme colour from `theme_palette.h` at render time.
4. **Originality (the checklist's rule, recorded here).**
   - Every path is drawn for this project.
   - No path is copied, traced, or auto-converted from an existing OS, icon pack, font or screenshot. That includes the operator's own mockup PNGs, which are reference images, not sources.
   - Each SVG carries `<!-- original: PRADYOS, DDR-1180 -->`. The PR adding it states, per file, what it depicts and that it was drawn by hand on the grid.
   - A reviewer can check this rule only by eye, so the operator review is part of the exit gate, not optional.
5. **Icon set (first cut).** It covers what the compositor and shell already draw:
   - dock items: terminal, files, settings, AETHER agent, network, power;
   - window controls: close, minimise, maximise;
   - status: battery, wifi, lock, mode toggle (Sovereign/Manual).

   The exact list is taken from `user/compositor.c` when the artwork PR is written, and recorded there.

## 3. Gate `ci-icon-check` (host-side; joins `tools/ci/hygiene_check.sh` as check twelve)

CLAUDE.md says "all eleven checks". When this gate lands, that line needs an operator edit, because CLAUDE.md is not edited on a side branch.

The gate is a stdlib-only Python tool, `tools/brand/icon_check.py`, in the same pattern as `png_palette.py`. For every `assets/brand/icons/*.svg` it runs these arms:

| Arm | Check | Vacuity on the unfixed tree |
|---|---|---|
| A | **Exists.** Every name in `assets/brand/icons/MANIFEST` has an SVG, and every SVG is in the manifest. | Red: no manifest. |
| B | **Subset.** The file parses with `xml.etree`, uses only the §2.3 elements, commands and attributes, has `viewBox="0 0 24 24"`, sets `stroke-width="2"` and uses `currentColor`. | Red: no files. |
| C | **Grid.** Every coordinate, curve control points included, lies in [2, 22]. That is the stroke centreline; with the 2-unit stroke, ink reaches [1, 23]. | Red: no files. |
| D | **Renders.** A scanline rasteriser in the same tool draws each icon at 16, 24, 32 and 64 px. Each render must be non-empty and keep its ink inside [1, 23] units scaled to the size. Its ink bounding box must match the 24 px render scaled to that size, within ±1.5 px. | Red: no files. |
| E | **Originality marker.** Every file carries the §2.4 comment. | Red: no files. |

**Mutants. Each lands on a different arm and must be shown red in CI before merge:**

|---|---|---|
